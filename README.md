# Hawaiʻi Postcards

A calm pixel-art vocabulary game for EAP 1 students at BYU–Hawaii. Each week, practice ten academic
words from your major while a place on Oʻahu wakes up around you.

**Play:** open the GitHub Pages link for this repo. Progress saves in your browser; use 💾 to download a
progress file and **Load progress** on the title screen to continue on another computer.

This repo holds only the built game. It's generated from the source project by `publish.py`, so
edit there, not here.

Educational and non-commercial. The paintings were made with Ideogram (non-commercial weights);
the voices are designed from text descriptions, with no real person's voice cloned.
